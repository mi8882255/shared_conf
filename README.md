# shared_conf

dotfiles: zsh, vim, tmux, Karabiner. Работает на macOS и Debian/Ubuntu.

## Установка

```sh
git clone git@github.com:mi8882255/shared_conf.git ~/shared_conf
~/shared_conf/install.sh
```

Нужен zsh (на Linux сначала `sudo apt install zsh && chsh -s $(which zsh)`). Повторный запуск безопасен. Скрипт:
- ставит `tmux ripgrep fzf` через brew (macOS) или apt (Debian/Ubuntu, плюс `xclip` и vim);
- прописывает в этот репозиторий личные `user.name`/`user.email`, чтобы не закоммитить сюда с рабочего адреса;
- делает симлинки `~/.vimrc`, `~/.tmux.conf`, `~/.inputrc` (существующие файлы переименовывает в `*.bak-<дата>`);
- на macOS кладёт правила Karabiner (см. ниже) и отключает раздельную историю вкладок Terminal (`~/.zshenv`);
- добавляет `source ~/shared_conf/zsh/zshrc` в `~/.zshrc`;
- ставит плагины tmux (tpm) и vim (vim-plug; для coc нужен node).

## Файлы

| файл | что это |
|---|---|
| `zsh/zshrc` | промпт, история, раскладка, fzf, git-команды |

## zsh

- Промпт `user@host dir (branch) $`. Если прошлая команда упала, красным показывается её код ошибки.
- История общая для всех вкладок, 500k строк. Повторы, `ls`, `ps`, `history` и команды, начинающиеся с пробела, в неё не пишутся.
- **↑ / ↓** ищут по истории команды, которые начинаются с уже набранного текста.
- **Ctrl-R** — нечёткий поиск по истории (fzf), **Ctrl-T** вставляет путь к файлу.
- **Не та раскладка.** Пишешь `пше ыефегы` и жмёшь Enter: строка заменяется на `git status`, но **не выполняется**. Проверь её и нажми Enter ещё раз.
  - Срабатывает, только если первое слово набрано кириллицей, такой команды нет, а в латинице она есть.
  - Таблица букв лежит в `zshrc`, внешних зависимостей нет.
  - `git ыефегы` не исправляется: первое слово `git` и так существует.

| команда | что делает |
|---|---|
| `gpush` | `git push -u origin HEAD` |
| `gpull` | `git pull --rebase --autostash` |
| `gcommit сообщение` | `git commit -am`, кавычки не нужны; предупреждает о `console.log` |
| `gco_clean <ветка>` | fetch + полная очистка (включая игнорируемые файлы) + switch + reset на origin, с подтверждением |
| `gsub_clean` | сброс всех сабмодулей на origin/HEAD, с подтверждением |
| `g_what2push` | коммиты и файлы, которые ещё не запушены |
| `g_notreleased [dev] [master]` | коммиты, которые есть только в одной из веток |
| `g_uncommit` | отменить последний коммит, изменения остаются |
| `g_reset_orig` | `reset --hard` на upstream |
| `ta` | tmux: подключиться к сессии `main` или создать её |
| `mosht host` | mosh на сервер сразу в tmux-сессию `main` |
| `simple_server [порт]` | примитивный HTTP-сервер, на всё отвечает 200 (проверить, доходит ли вебхук) |

## tmux

Префикс стандартный: **Ctrl-b**. На маках с Karabiner его даёт короткое нажатие **Caps Lock** (Caps, затем `h` — панель слева).

| клавиши | что делает |
|---|---|
| `Ctrl-b h/j/k/l` | переход между панелями |
| мышь | клик по панели, перетаскивание границ, прокрутка |
| `Ctrl-b [`, затем `v` … `y` | выделить и скопировать в системный буфер (в режиме vi); выделение мышью тоже копирует |
| `Ctrl-b Ctrl-p` | вставить из системного буфера |
| `Ctrl-b Ctrl-s` / `Ctrl-b Ctrl-r` | сохранить / восстановить сессии после перезагрузки (tmux-resurrect) |

Окна и панели нумеруются с 1, звонки отключены. Буфер обмена: на macOS `pbcopy`, на Linux `xclip`, а через ssh работает OSC52 (копируешь на сервере, попадает в буфер мака).

## vim

Номера строк (абсолютные и относительные). Поиск без учёта регистра, пока в запросе нет заглавных. Сворачивание по отступам, по умолчанию всё развёрнуто. Табы шириной 2. Длинные строки не переносятся. `y`/`p` работают с системным буфером. История undo сохраняется после закрытия файла. Leader — `,`.

| клавиши | что делает |
|---|---|
| `Ctrl-n` | дерево файлов (NERDTree) |
| `Ctrl-p` | поиск файла по имени (fzf) |
| `,a текст` | поиск по содержимому файлов (ripgrep) |
| `,f` + движение | easymotion, например `,fw`: прыжок к любому слову по букве-метке |
| `,w` | то же, что `Ctrl-w` (окна) |
| `Пробел` + символ | вставить один символ, не выходя из normal-режима |
| `Ctrl-s` (insert) | сохранить |
| `Ctrl-←` (insert) | новая строка ниже |
| `:FormatJSON` | отформатировать JSON |
| `gd` / `gr` / `gy` / `gi` | определение / использования / тип / реализация (coc) |
| `K` | документация под курсором |
| `,rn` | переименовать |
| `,p` / `,q` | prettier для файла / форматировать выделенное |
| `,ac` / `,qf` | действия с кодом / быстрое исправление |
| `[g` / `]g` | предыдущая / следующая ошибка |
| `if` / `af` | текстовый объект: тело функции / функция целиком (`vaf`, `dif`) |

Плагины:
- auto-pairs — закрывает скобки;
- fugitive — `:Git …`;
- gitgutter — `+ ~ -` у изменённых строк;
- coc + `coc-tsserver`, `coc-json`, `coc-eslint`, `coc-prettier` — ставятся сами.

## Раскладки и Caps Lock на macOS (Karabiner)

| клавиша (нажатая отдельно) | macOS | в Windows App (RDP) |
|---|---|---|
| fn | EN | `Ctrl+Shift+1` |
| правый ⌘ | RU | `Ctrl+Shift+2` |
| правый ⌥ | UA | `Ctrl+Shift+3` |
| Caps Lock | `Ctrl-b` (префикс tmux); зажатый с другой клавишей → Ctrl | то же |

В сочетаниях с другими клавишами fn, ⌘ и ⌥ работают как обычно. Раскладка выбирается по языку, поэтому подходит любая английская, русская или украинская.

`install.sh` делает всё сам (пропустить: `NO_KARABINER=1 ./install.sh`):
- ставит Karabiner-Elements через brew, если его нет (спросит пароль sudo);
- вписывает правила из `karabiner/layouts.json` в `~/.config/karabiner/karabiner.json` (логика в `karabiner/merge.jq`, перед изменением делается backup). Karabiner перечитывает файл сам;
- удаляет старые simple modifications для fn, правого ⌘ и правого ⌥ (иначе они перехватят клавиши), остальные не трогает;
- ставит «Press 🌐 key to» → Do Nothing.

Руками, один раз на каждом маке: при первом запуске Karabiner разрешить драйвер и Input Monitoring в System Settings → Privacy & Security. Это macOS из консоли не позволяет.

Один раз на каждой Windows-машине, куда заходишь по RDP: Параметры → Время и язык → Ввод → Дополнительные параметры клавиатуры → Сочетания клавиш для языков ввода. Назначь `Ctrl+Shift+1` для English, `Ctrl+Shift+2` для Русского, `Ctrl+Shift+3` для Українського.

Порядок клавиш меняется в `karabiner/layouts.json`.
